# Krisna — Interactive 3D Portfolio

Project ini mempertahankan HTML, CSS, dan JavaScript portfolio asli yang kamu kirim, lalu menambahkan efek kartu 3D.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder ini di VS Code.
3. Jalankan `index.html` menggunakan Live Server, atau buka file HTML langsung di browser.

Tidak membutuhkan npm atau package tambahan.

## Yang dipertahankan
- Loader dan progress percentage
- Navbar dan menu mobile
- Dark/light mode
- Bagian About, Skills, Projects, Certificates, Contact, dan footer
- Animasi scroll reveal dan active navigation

## Yang ditambahkan
- Efek tilt 3D yang mengikuti pointer pada profile card dan project cards
- Glow yang mengikuti posisi pointer pada kartu
- Efek 3D pada isi kartu profil
- Dukungan reduced-motion untuk pengguna yang mengurangi animasi

## Catatan
- File CV masih mengarah ke `assets/cv-krisna.pdf`; taruh file CV kamu di lokasi itu supaya tombol download berfungsi.
- Ganti link GitHub/LinkedIn contoh dengan profil milikmu sebelum dipublikasikan.
